# Rock Bag Filter Units — Website Rework

A modern, single-page rework of [www.rockbagfilterunits.com](https://www.rockbagfilterunits.com).

## What's here

- `index.html` — fully self-contained site (inline CSS + JS, inline SVG artwork, no external dependencies). Open it directly in a browser or serve it from any static host (GitHub Pages, Netlify, cPanel, etc.).

## Sections

1. **Hero** — value proposition with key stats (0.5–12 t sizes, 100+ yr life, worldwide supply)
2. **Product** — what a Rock Bag Filter Unit is, with a cutaway diagram
3. **Applications** — bridge piers, coastal defence, ports & harbours, offshore wind, subsea cables & pipelines, flood/emergency works
4. **Specifications** — standard sizes, PE/HDPE net materials, design life, traceability & testing
5. **Why Rock Bags** — speed, stability, environmental benefit, certified quality
6. **Installation** — fill → lift → place
7. **About** — company background, Brendale QLD HQ, worldwide supply
8. **Contact** — address, email, and enquiry form

## Notes

- Fully responsive (mobile nav with hamburger menu) and uses scroll-reveal animations that respect `prefers-reduced-motion`.
- The enquiry form currently uses a `mailto:` action to `design@rockbagfilterunits.com`; swap in a form backend (Formspree, Netlify Forms, PHP handler) for production.
- Replace the placeholder SVG illustrations with real project photography when available for maximum impact.
